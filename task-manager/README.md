# 日常任务管理软件

一款功能丰富的桌面任务管理软件，基于 Electron + Vue 3 + TypeScript 开发。

## 功能特性

### 1. 任务添加
- 支持设置任务标题、时间段、任务主题、任务细节
- 主题可选，支持添加新主题（自定义名称和颜色）
- 支持添加多个子任务（分任务）

### 2. 任务类型
- **当天任务**：仅在指定日期显示和执行
- **长期任务**：连续多天进行的任务，设置开始和结束日期

### 3. 任务管理
- 删除任务时提供三种确认方式：
  - 标记为完成：任务已完成
  - 结束任务：提前结束任务，保留记录
  - 取消任务：取消此任务，不保留进度

### 4. 任务提醒
- 可设置提前提醒时间（5/10/15/30/60分钟）
- 任务开始和结束时都会弹出小窗口提醒
- 同时发送系统通知

### 5. 任务进行中窗口
- 任务开始时自动打开固定窗口
- 显示任务细节和子任务列表
- 支持子任务勾选完成
- 支持暂停/继续任务，需记录暂停原因
- 显示实时计时和暂停记录

### 6. 统计功能
- 主题时间分布可视化
- 任务完成度统计
- 每日任务分布和执行情况
- 暂停次数和总暂停时长统计

## 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **桌面框架**: Electron
- **数据存储**: localStorage（本地存储）

## 安装与运行

### 开发模式

```bash
# 安装依赖
npm install

# 启动开发服务器（含 Electron）
npm run dev
```

### 构建生产版本

```bash
# 构建并打包
npm run build
```

### 仅构建前端

```bash
npx vite build
```

## 使用说明

1. **添加任务**：点击右上角「+ 添加任务」按钮
2. **设置任务信息**：填写标题、选择类型、设置时间、选择主题等
3. **开始任务**：点击任务卡片上的「开始」按钮
4. **暂停任务**：在任务进行中窗口点击「暂停任务」，填写暂停原因
5. **完成任务**：点击「完成任务」或在主界面点击「完成」
6. **删除任务**：点击「删除」按钮，选择删除方式
7. **查看统计**：右侧面板查看今日统计数据
